# Koleksi 20 Template Landing Page Tour & Travel Indonesia

Koleksi lengkap **20 landing page premium** untuk agensi tour & travel di Indonesia, terinspirasi langsung dari **tema-tema terlaris ThemeForest** (seperti *Grand Tour, SetSail, Roam, Traveler, GoTravel, Wanderland, Tevily, Altair, Tripo*, dll).

Setiap landing page telah diadaptasi penuh dengan **data riil destinasi wisata Indonesia**, harga paket dalam Rupiah, jadwal keberangkatan, itinerary lengkap hari 1-3/4, fasilitas include/exclude, filter pencarian dinamis, video modal 16:9, dan **proteksi paywall pratinjau 45 detik** dengan call-to-action pemesanan via WhatsApp (+62 878-8127-2246).

Dibangun menggunakan **HTML5 murni + Tailwind CSS CDN + Font Awesome 6 + Vanilla JS**. Ringan, tanpa build-step, langsung jalan di browser apapun!

## ✨ Fitur & Arsitektur Landing Page

1. **100% Free Stock Photography**: Menggunakan foto resolusi tinggi bebas royalti (Unsplash) bertema destinasi wisata Indonesia asli.
2. **Mobile First & Fully Responsive**: Tampilan mobile dilengkapi burger drawer navigasi mulus, di desktop navigasi bersih tanpa ikon cart/shop.
3. **Fungsionalitas Interaktif Penuh (No Dead Links)**:
   - **Filter Pencarian Real-Time**: Kolom pencarian di hero langsung memfilter kartu paket wisata yang relevan.
   - **Modal Detail Itinerary & Booking**: Pop-up dialog kaya informasi berisi rute perjalanan hari demi hari, fasilitas include/exclude, dan form pemesanan instan via WhatsApp.
   - **Modal Video 16:9**: Pemutar video drone pemandangan alam responsif.
   - **A11y**: Tombol `Escape` (ESC) & klik backdrop langsung menutup modal/drawer yang terbuka.
4. **Proteksi Paywall Preview (45 Detik)**:
   - File `paywall.js` modular: kunci layar dengan blur 45 detik, toast reminder di detik ke-35, CTA WhatsApp ke **+62 878-8127-2246**.
   - Zero-hassle removal (`enabled: false` saat klien melunasi pembelian).
5. **Showcase Gallery Interaktif (`index.html`)**:
   - Menampilkan screenshot seluruh 20 tema dengan filter kategori (Bahari, Gunung, Budaya, Luxury/Honeymoon).
   - Dilengkapi **Live Quick View Modal** dengan switcher viewport (Desktop, Tablet, Mobile).
